Everything renders from CSS variables named exactly as in globals.css — --ground, --panel, --ink, --accent, --line, --annotation, --alarm, --go. In the app these move from :root onto [data-theme] blocks; the @theme inline map and every component stay untouched. Lists are compact hairline rows, subject cards have no colour rail, and accents use each theme's default. The rows also preview the proposed additions — inline search, filter chips, avatar status rings, and circular count badges.
